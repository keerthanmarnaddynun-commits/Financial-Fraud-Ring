3. FAILURES AND RETRIES (EXACT ERROR LINES)
------------------------------------------
- STEP 1.1: GraphFrames binary incompatibility on PySpark 4.2.0:
  'java.lang.NoSuchMethodError: org.apache.spark.sql.SparkSession.implicits()Lorg/apache/spark/sql/SQLImplicits;'
  Resolution: Implemented Spark-native DataFrame iterative graph algorithms with local checkpointing.
- STEP 1.5: Ambiguous column reference in LPA convergence test:
  'AnalysisException: [AMBIGUOUS_REFERENCE] Reference `community_id` is ambiguous'
  Resolution: Added explicit column alias `new_community_id` prior to join.
- STEP 1.7: Training sampling undershoot on small debug fractions:
  Sampling returned fewer negatives than requested due to Bernoulli variance on small datasets.
  Resolution: Switched to order-by rand with limit for small samples, 1.5x oversampling buffer for large sets.
- STEP 1.8: Distributed batch scoring empty partition schema mismatch:
  'ValueError: Number of columns does not match number of column names'
  Resolution: In mapInPandas generator, return pd.DataFrame(columns=output_cols) when partition iterator is empty.
- STEP 1.12: Git index.lock permission denied in standard sandbox:
  'fatal: Unable to create .git/index.lock: Permission denied'
  Resolution: Executed git index write commands with elevated execution mode.

4. DECISIONS TAKEN (DEFAULTS USED)
---------------------------------
- Single Spark Session: Maintained unified builder in spark_session.py configured with local[*] and 8GB driver memory.
- Native Graph Algorithms: Iterative graph algorithms utilize localCheckpoint(eager=True) every 2 iterations to truncate RDD lineage.
- Leakage Prevention: Excluded `step` and `isFlaggedFraud` from ML feature lists; evaluated `isFlaggedFraud` as M0 rule baseline.
- Threshold Selection: Tuned threshold on validation set (max F1) and applied out-of-sample to test set.
- Accepted Outputs Promotion: Archived legacy run to archive/outputs_prev_20261117_091008/ and promoted 20261117_c1-full to outputs/.

5. SURPRISES NOTICED
--------------------
- Simulator Artifact Signal: On all splits, removing simulator balance error features (errorBalanceOrig, errorBalanceDest) drops F1 by 0.08 to 0.15 (e.g. from 0.996 to 0.912 on time split; from 0.990 to 0.840 on group_dest split), indicating substantial model reliance on simulator accounting balance discrepancies.
